# 光栈 Lumen

**好不容易生成的那张图，别再找不到了。**

灵感图存了一堆，满意的版本藏在文件夹深处，提示词还在另一个窗口。等到下一次要接着做，又得把这些东西重新找齐。

光栈把图片、视频、音频和制作记录放在一个 Mac 工作台里：在图库挑素材，到画布接着创作，生成的结果再回到对应作品。下一次打开，继续上次的想法。

[下载 0.8.0](https://github.com/limyum-creator/lumen-releases/releases/tag/v0.8.0) · [快速上手](光栈快速上手.txt) · [让 AI 接入](Agent连接指南.txt)

适用于 Apple Silicon Mac（M 系列芯片），macOS 14 及以上。

## 找到一张图，也找回它的来龙去脉

同一件作品可以放下多次尝试。把喜欢的那张设为图库首图，其他版本仍在；按空格快速翻看，或打开版本比较，把两张放在一起看细节。

有生成记录的素材，可以查看当时的提示词、种子、模型和参数。英文提示词支持中文翻译显示，复制和继续生成仍用原文。少一点“这张到底怎么跑出来的”，多一点有据可循的调整。

- 图片按原比例排列，视频和音频也能在同一个库里查看、播放。
- 按作品名、文件名、已有提示词或模型搜索，配合标签、喜欢和分类缩小范围。
- 添加监听文件夹后，光栈会把新素材复制进库，保留来源；应用关闭期间的新增文件，下次打开再补收。

## 把一个想法，摊开在画布上

左边摆角色参考，中间写提示词，旁边留一句“光线再暖一点”。接上产出卡，这次要用哪些素材、准备改哪里，一眼能看清。

图片、视频、音频、提示词、便签和工作流参数都可以放到画布。卡片能拖动、缩放、框选和成组移动；常调的参数单独展开，留在手边。提示词双击编辑，回车保存，Shift＋回车换行。

做一张图，可以从一个单元开始。做连续内容，就按**项目 → 单集 → 单元**展开：共用的角色与场景留在共享层，每个单元保留自己的参考和产出，分镜里继续整理镜头、台词、声音和时长。

## 接上工作流，在这里完成下一轮尝试

光栈可连接 **ComfyUI**，也可按链接或 ID 添加 **RunningHub** 工作流。每张产出卡独立选择工作流、提示词、参考素材和参数；需要连着做时，可以按依赖关系运行整个单元。

工作流多了，就在左侧“工作流”里隐藏暂时不用的、调整常用顺序。刷新会保留整理结果，新识别的条目默认显示。

- 种子可以固定、随机一次，或设为每次随机；开启每次随机后显示 `-1`，每个任务会记住实际使用的种子。
- 队列和历史保留任务记录，有可用媒体时可直接快速预览。
- RunningHub 生成完成后自动下载并收进库，支持从平台返回的 ZIP 中提取图片、视频和音频。
- 产出卡默认跟随最新结果。某一版已经合适，就点“固定此版本”；图库首图可以另外选，各管各的。

## 让 AI 看懂你正在做什么

把设置中导出的 **AI 接入文档**交给具备本机配置能力的 OpenClaw 等 Agent，它就有了连接光栈所需的说明和配置。

接入后，可以让它读取项目和素材，整理单集与单元，修改提示词、分镜和素材引用。改动会回到光栈里的同一份制作资料，你可以接着看、接着改。

MCP 服务随应用提供，无需另外安装 Python。当前接口支持这些制作资料的读写，不提供生成、批准素材或定版操作。

## 图库放在哪里，由你决定

首次打开时选择本机文件夹，新建或打开图库。素材、作品版本关系和制作资料保存在这里，浏览与整理不需要生成后端在线。

使用云端生成时，本次提示词和参考素材会发送到所选平台；RunningHub API Key 保存在本机钥匙串。备份时请保留整个图库，包括隐藏的 `.lumen` 文件夹，它保存着版本关系和制作状态。

## 开始使用

1. 从[下载页](https://github.com/limyum-creator/lumen-releases/releases/tag/v0.8.0)获取 `.dmg`，把“光栈.app”拖进“应用程序”。
2. 首次打开，选一个空文件夹新建图库，或打开已有光栈图库。
3. 先添加几张素材试试空格预览。想开始生成，再去设置里连接 ComfyUI 或 RunningHub。

应用尚未经过 Apple 公证。首次打开若被系统拦截，可在“系统设置 → 隐私与安全性”中允许打开。

启动时会检查更新，有新版才提醒；也可以在设置里手动检查。更新时退出旧版，用新应用替换，保留原图库即可。GitHub 自动生成的 `Source code` 压缩包不是安装包。

### 目前支持到哪里

- Windows 和 Intel Mac 版本暂未提供。
- ComfyUI 的模型、节点和 RunningHub 的账号、额度需自行准备。自定义工作流的兼容性取决于节点与输入输出结构；RunningHub 按链接添加，暂不自动同步账号的全部工作流。
- 自动内容分级需另装离线组件；音视频播放受系统支持的编码限制。
- 分镜用于组织制作内容，尚未提供视频剪辑时间线。
