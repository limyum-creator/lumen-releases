光栈快速上手
把素材、生成版本和创作项目放在一起管理。

光栈是什么
光栈是一款 Mac 本地视觉素材与创作工作台。你可以用它浏览和整理图片、视频、音频，比较同一作品的不同版本，也可以把提示词、参考素材、产出和分镜放进项目画布。资料保存在自己选择的本机图库里。
只想管理素材，可以先用图库；想做连续创作，再使用创作工作台。ComfyUI 和外部 AI 都是可选连接，不是看图的前提。当前内测适用于 Apple Silicon Mac，安装要求 macOS 14 或更新系统。

第一次打开：先完成这三步
1. 安装：将 DMG 内的光栈拖进应用程序。首次打开若被系统拦截，可到系统设置 → 隐私与安全性允许打开。当前为免费内测版，无需激活码，没有授权到期限制。
2. 选择图库：新建图库请选择空文件夹；已有光栈图库选择“打开已有图库”。图库是存放素材和制作记录的总目录，不要把任意已有图片文件夹当作光栈图库打开。
3. 加入素材：在设置 → 图库与连接中添加“监听文件夹”，让光栈把其中的素材复制入库并保留来源。也可把图片放进图库根目录或“原图”目录后检查收图。应用退出后暂停收图，下次启动会补扫。

建议先试一次：添加一个只有几张图片的监听文件夹，点击“立即检查收图”，然后回图库单击、空格预览、双击打开详情。确认熟悉后再加入更多素材。

你会用到的几个地方
• 图库：浏览、搜索、喜欢、标签和分类。生成图库、摄影图库、参考库、资产库用于区分不同用途。
• 创作：按项目组织单集和单元，在画布上搭配提示词、参考素材和产出卡；在分镜视图整理镜头。
• 设置：管理图库位置、监听来源、ComfyUI连接、离线分级组件、Agent连接等。
• 游戏：当前尚未开放。

看素材与比较版本
单击选中，空格快速预览，双击进入详情，Esc返回。Command点击可追加选择，Shift可连续选择。左下爱心用于喜欢作品；搜索可查作品名、版本文件名以及已有提示词和模型记录。
同一作品可以保存多个版本。图库显示的“首图”只是封面，不等于最终采用版；查看器内可以切换版本、比较图片或播放支持的音视频。缺少生成记录时显示未记录，不会补造参数。支持的容器不代表所有视频编码都能播放。

如何开始一个创作项目
1. 在“创作”界面建立项目，并按需要添加单集和单元。单元也可理解为P，是一段制作内容的组织范围，不一定只对应一个镜头。
2. 在画布空白处右键添加提示词、便签、产出或素材卡。拖动卡片调整布局，空白处按住左键拖动框选多张卡片。
3. 用连接点建立关系。把参考或提示词接到产出卡后，检查对应输入用途。普通关系线和实际生成输入的用途不同；参数卡连接表示所属产出。
4. 需要修改连线时，单击选中后按Delete可删除；拖动前半段改来源，拖动后半段改目标，拖到空白松开会删除该线。删除关系不会删除原素材。
5. 在“分镜”里填写镜头描述、台词、声音和时长，并按需要关联素材与单元。先做好内容组织，不连接生成后端也可以保存制作资料。

如果你使用 ComfyUI
在设置里连接自己可访问的ComfyUI，先测试连接，再在产出卡选择工作流、模型和参数。ComfyUI对应的模型与节点需要由使用者准备；光栈不附赠模型，也不保证兼容所有自定义节点或工作流。
给产出卡接入参考与提示词，检查输入后再由你提交生成。提交成功、生成完成、文件入库与最终采用是不同步骤；结果出来后仍需你查看和选择版本。本软件当前不是视频剪辑时间线，也不自带在线生成服务。

如果你使用 RunningHub（云端接入试用）
在设置 → 连接 → RunningHub 云端生成中选择站点，保存自己的 API Key，再粘贴工作流链接或数字 ID 并点击“读取并添加工作流”。密钥只存入本机钥匙串；读取工作流不会提交生成。如果出现多个主提示词候选，先按内容预览选择填写画面描述的入口，再点“确认入口并保存”；翻译模板等其他文字会保留。橙色提示表示尚需选择、红色表示失败、绿色表示保存成功，均附图标与明确文字。回到产出卡，刷新工作流列表后选择 RunningHub 开头的条目，即可接提示词和参考素材、调整已识别参数。
生成会把本次提示词及参考素材上传到所选 RunningHub 站点，并使用你的平台额度。首版支持可明确识别主提示词、标准媒体输入和单个保存输出的工作流，复杂控件或多个输出会提示暂不支持；不自动列出账号全部工作流。参数按工作流现值解析，不提供云端完整模型下拉列表。需要更新已添加工作流时，再次读取同一链接，然后在产出卡刷新参数。
平台返回 ZIP 时会自动解出其中支持的图片、视频和音频并归档；当前不支持 RAR、7z、嵌套或加密包，最多 64 个媒体，解压媒体合计不超过 2 GiB。
任务会记录平台编号并持续查询；如果提交超时而没有取得编号，先到 RunningHub 核对任务，不要重复生成。已取得编号的任务可在网络恢复后继续查结果。当前为待真实账号联调的接入版本，平台权限、节点兼容性与大文件限制仍需实际验证。

如果你想让 AI 帮忙
设置 → 图库与连接 → Agent连接 → “导出AI接入文档”。把文档交给运行在同一台Mac、具备本地配置能力的AI，让它按文档接入并先读取项目验证。
AI可以读取项目和素材、按你的要求整理单集/单元、改提示词与分镜、调整已有素材引用。当前MCP不提供生成、新建项目、批准素材或定版操作；这些不应因接入而自动发生。不使用AI不影响图库与手动画布操作。

分类、删除与数据保留
自动分级需要另外安装并启用离线分级资源包；没有模型时素材保持未分级，不会自动认定安全。人工选择优先。
画布里的移除引用与图库里的删除不是同一件事。删除前看清确认范围；软删除与彻底清理也不同。想备份时，保留整个图库，包括隐藏的“.lumen”目录；其中有作品版本关系和人工制作状态，不要当作缓存删除。原素材备份仍由你自己安排。

更新和反馈
退出光栈和Agent的旧连接，用新版应用替换原安装位置，再重新打开。正常替换App会保留应用外的图库、设置；移动应用或切换图库后，需要重新导出AI配置。涉及数据结构变化时，按该版本说明先备份。
遇到问题请告诉邀请者：应用版本、正在做什么、预期结果与实际结果，并附错误文字或截图。分享截图前注意其中是否有私密素材。不要发送API密钥、私钥或整个私人图库来报告普通问题。

软件更新
每次打开软件会后台检查 GitHub 上的已发布版本，有新版时提示下载，没有更新时不打扰。也可在设置 → 通用点击“检查更新”。点击“下载更新”通过浏览器下载安装包，退出旧版后替换应用，保留原图库和设置；不会自动安装或覆盖制作资料。
